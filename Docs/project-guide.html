02

Kiến trúc dự án

Layer dependencies

  • Domain — Entity, Event, ValueObject. Không phụ thuộc gì.
  • Application → Domain. CQRS (MediatR), Interfaces, Behaviors.
  • Infrastructure → Application + Domain. EF Core, Hangfire, JWT, SMTP.
  • Api → Application + Infrastructure + Domain. Controllers, Middleware.

Key patterns

  • Domain Events — entity gọi AddDomainEvent(), dispatch sau SaveChanges.
  • MediatR Pipeline — LoggingBehavior → ValidationBehavior → Handler.
  • Soft delete — IsDeleted flag, dùng SoftDelete().
  • Hangfire — job ID = Task Guid. RecurringJob theo cron.
  • Retry — exponential backoff, max MaxRetries lần.

Event Handler map

  • TaskCreatedEvent → TaskCreatedLogHandler (log info)
  • TaskCompletedEvent → TaskCompletedLogHandler (log info) + TaskCompletedMetricsHandler (increment counter)
  • TaskFailedEvent → TaskFailedLogHandler (log error) + TaskFailedMetricsHandler (increment counter) + SendEmailHandler (gửi email admin)
  • TaskPausedEvent → (domain event raised, chưa có handler — thêm khi cần)

CI Workflow — .github/workflows/ci.yml

Trigger: push lên main hoặc develop, hoặc mở Pull Request vào main.

CI spin up một container PostgreSQL 18 để các integration test có database thật — không mock DB. Test kết quả được upload thành artifact .trx trên GitHub.

.github/workflows/ci.yml — tóm tắt các bước 
# 1. Checkout code
# 2. Setup .NET 10
# 3. dotnet restore
# 4. dotnet build --no-restore -c Release
# 5. dotnet test (206 tests)
#    env: ConnectionStrings__DefaultConnection=Host=localhost;...
#         Jwt__Secret=ci-test-secret-...  (≥32 ký tự)
#         ASPNETCORE_ENVIRONMENT=Testing
# 6. Upload test-results artifact (.trx)

Tại sao cần PostgreSQL trong CI?

  • Repository tests chạy trên SQLite in-memory (đủ cho unit test)
  • Api.Tests dùng WebApplicationFactory + SQLite — không cần Postgres
  • Nếu sau này có integration test thật với Postgres → sẵn sàng

Tại sao cần appsettings.Testing.json?

  • appsettings.json để JWT Secret trống (security fix)
  • WebApplicationFactory set env = Testing
  • ASP.NET Core tự load appsettings.Testing.json → có JWT key cho test
  • File này chứa key giả, an toàn để commit
06

CD Workflow — .github/workflows/cd.yml

Trigger: push vào main. Hai job: docker (build + push image) và deploy (SSH vào server).

1
Job docker — Build & push image lên GHCR
Dùng docker/build-push-action build Dockerfile multi-stage, push lên ghcr.io/huuquandev/task-scheduler-api với 2 tag: :latest và :<commit-sha>. Dùng GITHUB_TOKEN tự động — không cần secret thủ công.
2
Job deploy — SSH vào server (optional)
Chỉ chạy sau khi job docker thành công. Check DEPLOY_HOST secret — nếu chưa cấu hình thì SKIP (không fail). Khi có host: SSH vào server, chạy docker compose pull → docker compose up -d → docker image prune -f.
3
Secrets cần thêm vào GitHub Actions
Vào GitHub repo → Settings → Secrets and variables → Actions, thêm: DEPLOY_HOST, DEPLOY_USER, DEPLOY_SSH_KEY, DEPLOY_PATH. Tuỳ chọn: GHCR_TOKEN + DEPLOY_GHCR_USER nếu repo private.

Test một Task theo đúng vòng đời

Quy trình dưới đây test toàn bộ lifecycle của một task: tạo → activate → trigger thủ công → xem log → pause → resume. Dùng Swagger UI hoặc curl/Postman đều được.

ℹ
Bước 0 — Lấy JWT token trước. Tất cả endpoint đều yêu cầu [Authorize]. Đăng ký tài khoản rồi login để lấy token, paste vào header Authorization: Bearer <token>.
0
Đăng ký & đăng nhập
POST /api/v1/auth/register
{ "email": "dev@test.com", "password": "Test@1234", "username": "devuser" }
POST /api/v1/auth/login → lưu lại "token"
{ "email": "dev@test.com", "password": "Test@1234" }
1
Tạo task — trạng thái: Pending
Command đơn giản: echo Hello Task. Cron * * * * * = chạy mỗi phút.
POST /api/v1/tasks
{
  "name":           "My First Task",
  "description":    "Test vòng đời task",
  "cronExpression": "* * * * *",
  "command":        "echo Hello Task",
  "maxRetries":     2
}
// Response: { "data": "<task-guid>" } → lưu lại ID này
2
Kích hoạt task — trạng thái: Active
Task Pending không chạy. Phải activate trước để Hangfire đăng ký RecurringJob.
POST /api/v1/tasks/{id}/activate
# Không cần body. Response: { "data": true }
# Hangfire dashboard: thấy RecurringJob với ID = task-guid
3
Trigger thủ công — trạng thái: Running → Active
Không cần đợi đến phút tiếp theo. Trigger enqueue job ngay vào Hangfire.
POST /api/v1/tasks/{id}/trigger
# Rate limited: tối đa X lần/phút (RateLimitExtensions)
# Response: { "data": true }
# Xem Hangfire dashboard: /hangfire → Jobs → Enqueued
4
Xem kết quả thực thi
GET /api/v1/execution-logs/{taskId}
# Response: danh sách log, mỗi log có:
#   status: Success / Failed
#   durationMs: thời gian chạy
#   exitCode: 0 (success) hoặc khác
#   errorMessage: lý do nếu fail
5
Pause task — trạng thái: Paused
Chỉ pause được khi đang Active. Hangfire RecurringJob bị remove.
POST /api/v1/tasks/{id}/pause
# Response: { "data": true }
6
Resume task — trạng thái: Active
POST /api/v1/tasks/{id}/resume
# Hangfire RecurringJob được đăng ký lại
7
Test kịch bản lỗi & retry
Tạo task với command lỗi để xem retry logic và email notification.
Tạo task lỗi
{
  "name":           "Failing Task",
  "cronExpression": "* * * * *",
  "command":        "exit 1",
  "maxRetries":     1
}
# → activate → trigger
# Lần 1: fail → RetryCount=1, schedule retry sau 30s
# Lần 2: fail → RetryCount=2 > MaxRetries=1 → Status=Failed
# Email gửi tới Notifications:AdminEmail (nếu đã cấu hình)
8
Xem dashboard & health
Các endpoint hữu ích để monitor hệ thống.

Secrets & Configuration

⚠
JWT Secret & DB Password đã bị lộ trong git history. Sau khi setup, hãy rotate: tạo JWT secret mới (openssl rand -base64 48) và đổi mật khẩu PostgreSQL. Cập nhật lại GitHub Actions secrets và file .env local.

Config flow: local dev

  • appsettings.json — cấu trúc, giá trị trống
  • appsettings.Development.json — override với secrets thật (gitignored)
  • ASP.NET Core merge tự động theo priority

Config flow: production / Docker

  • Secrets inject qua environment variables
  • ConnectionStrings__DefaultConnection → ConnectionStrings:DefaultConnection
  • Lấy giá trị từ file .env (docker compose) hoặc GitHub Actions secrets
